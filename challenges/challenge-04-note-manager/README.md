# Challenge 05 — Note Manager

Build a small note manager app that fetches saved notes from an API and lets users add, edit, and delete notes using React Query.

This challenge focuses on real query and mutation flows with clear loading, success, and error handling. The app should use `useQuery` for fetching notes and `useMutation` for create/update/delete actions.

Use the provided API helper at `challenge-05-note-manager/api/notes.api.js` or call `https://jsonplaceholder.typicode.com/posts` directly for note CRUD operations.

The goal is to practice solid React Query patterns while keeping the UI simple and user-friendly.
